💱 Conversor de Monedas
Este proyecto es una aplicación de consola desarrollada en Java que permite convertir diferentes monedas utilizando 
datos actualizados obtenidos desde una API de tasas de cambio.

🚀 Funcionalidades
1. Dólar estadounidense → Peso mexicano
2. Peso mexicano → Dólar estadounidense
3. Peso mexicano → Yuan chino
4. Yuan chino → Peso mexicano
5. Peso mexicano → Yen japonés
6. Yen japonés → Peso mexicano
7. Dólar estadounidense → Peso argentino
8. Peso argentino → Dólar estadounidense

El usuario solo debe seleccionar una opción del menú e ingresar el monto que desea convertir.
El programa mostrará el resultado indicando la moneda de origen y la moneda de destino.

🛠 Tecnologías 
* Java 17
* Maven
* Gson (para convertir JSON a objetos Java)
* API de tasas de cambio

🌐 API utilizada
La aplicación obtiene las tasas de cambio desde una API externa que devuelve los datos en formato JSON.
Estos datos son procesados dentro del programa para realizar las conversiones entre monedas.

⚙️ Cómo ejecutar el proyecto

1. Clonar el repositorio
git clone https://github.com/tu-usuario/conversor-monedas.git
2. Abrir el proyecto en IntelliJ IDEA o cualquier IDE compatible con Java.
3. Esperar a que Maven descargue las dependencias automáticamente.
4. Ejecutar la clase:
Main.java
5. Usar el menú de la consola para realizar conversiones de monedas.
